# Cognitive Effects of Caffeine Dosage on Memory and Reaction Time

## Overview
This project examines the empirical relationship between caffeine dosage, memory retention scores, and reaction times using PSPP (an open-source alternative to IBM SPSS).

*Note: This analysis was conducted using a synthetic (demo) dataset created for statistical practice and methodology demonstration.*

## Dataset Description
- **Data Source:** Synthetic / Demo Dataset (Created for SPSS/PSPP practice purposes)
- **Sample Size (N):** 10 participants
- **Variables:**
  - `Caffeine_Dose_mg`: Continuous (0mg, 100mg, 200mg)
  - `Reaction_Time_ms`: Continuous (in milliseconds)
  - `Memory_Score_100`: Continuous (scale 0–100)

## Key Findings (Pearson Correlation Analysis)
1. **Caffeine vs. Memory Score:** Strong positive correlation ($r = .968, p < .001$). Higher caffeine dosage significantly improves memory recall scores.
2. **Caffeine vs. Reaction Time:** Strong negative correlation ($r = -.980, p < .001$). Caffeine dosage reduces reaction time, indicating faster cognitive processing speed.
3. **Memory Score vs. Reaction Time:** Strong negative correlation ($r = -.996, p < .001$).

## Software Used
- PSPP (IBM SPSS syntax compatible)

## APA Style Reporting
- A Pearson correlation coefficient was computed to assess the linear relationship between caffeine dosage and memory scores. There was a statistically significant positive correlation between the two variables, $r(8) = .968, p < .001$.
